# ParCool × Stamina [DLTB] Bridge (Forge 1.20.1)

Мод-міст: ParCool перестає мати власну шкалу витривалості, усі його дії (біг, вальт, стрибки зі стін, перекати тощо)
беруть і витрачають витривалість зі шкали **Stamina [DLTB]**. Відновлення, виснаження і саму шкалу на екрані
веде DLTB.

Працює з **ParCool 4.x** (остання для 1.20.1 на момент написання: 4.0.1.5). У серії 3.x тип витривалості зашитий
в код ParCool, там міст неможливий.

## Як зібрати (без встановлення чого-небудь на комп'ютер)

1. Створіть на GitHub новий (можна приватний) репозиторій і завантажте в нього вміст цієї папки
   (разом з `libs/`, `gradle/`, `.github/`).
2. Відкрийте вкладку **Actions**. Збірка запуститься сама (або натисніть *Run workflow*).
3. Коли збірка зелена, відкрийте її й завантажте артефакт `parcool-dltb-bridge`: усередині буде `.jar`.

Локально: потрібна Java 17, команда `./gradlew build`, результат у `build/libs/`.

## Як встановити

На клієнті **і** на сервері (якщо граєте на сервері) в папці `mods` мають лежати:

- Forge 1.20.1 (47.4.x)
- Kotlin for Forge
- ParCool 4.x
- Stamina [DLTB]
- цей міст (`parcool-dltb-bridge-1.0.0.jar`)

Потім увімкніть тип витривалості. Відкрийте `parcool-server.toml`
(для світу: `saves/<світ>/serverconfig/`, для сервера: `world/serverconfig/`) і знайдіть розділ `[stamina]`:

```toml
[stamina]
stamina_type = "parcooldltb:dltb"
```

Перезапустіть гру або світ.

## Налаштування

`config/parcooldltb-common.toml`:

- `cost_scale` (за замовчуванням `0.5`). ParCool за замовчуванням має шкалу 2000, а DLTB 1000, тому множник 0.5
  зберігає пропорції витрат. Збільшіть, щоб паркур сильніше втомлював, зменшіть, щоб він був дешевшим.

### Подвійне списання при бігу

DLTB сам списує витривалість за спринт, а в ParCool дія `fast_run` теж має вартість. Якщо біг витрачає забагато,
у `parcool-server.toml` знайдіть розділ дії `fast_run` і поставте `cost_working = 0`
(те саме за потреби для інших дій, які вже покриває DLTB).

## Як це працює

- Міст реєструє тип витривалості `parcooldltb:dltb` через офіційний API ParCool (`RegisterParCoolStaminaTypeEvent`).
- Читання: клієнтська копія шкали DLTB (`ClientStaminaData`), значення і стан виснаження.
- Витрата: ParCool рахує вартість на клієнті, міст збирає її за тік і одним пакетом шле на сервер, де вона
  списується через публічний `StaminaAPI` DLTB. Так сервер залишається єдиним джерелом правди.
- Відновлення і виснаження: повністю на боці DLTB.
